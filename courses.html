Python Foundations

Від першого рядка коду до власних Python-проєктів.

Курс показує, як працює логіка програмування, і допомагає дійти до фінальної мінігри або власного невеликого застосунку.

Модулі 23
Доступ 6 місяців
Формат Self-Study або Full Support

Для кого

Для тих, хто хоче зрозуміти основи програмування, навчитися мислити логікою коду і створити свій перший Python-проєкт.

Що вивчиш

Змінні, типи даних, умови, цикли, списки, словники, функції, модулі та базову структуру реального коду.

Що створиш

Фінальний проєкт на Python на базі пройдених тем. На чинному сайті це описано як власна мінігра.

Модулі 15
Доступ 6 місяців
Формат Basic або Pro Support

Для кого

Для тих, хто хоче розібратися, як влаштовані сайти, і навчитися створювати власні адаптивні сторінки без досвіду.

Що вивчиш

Структуру HTML, стилізацію через CSS, роботу з текстом, зображеннями, формами та адаптивним layout через Flexbox.
